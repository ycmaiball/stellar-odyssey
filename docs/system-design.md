# 星际飞船游戏系统方案

> 角色：星际飞船游戏系统设计师
> 范围：装配 → 出航 → 战斗 → 返航维修 → 再装配 的完整闭环。本文档是设计说明，落地代码见下文「实现映射」。

---

## 1. 核心循环

```
首次进入
  └─▶ 装配台（基础装备，仅一套）
        ├─ 用 CR 解锁更高级船体 / 引擎 / 护盾 / 武器 / 驾驶舱 / 尾翼 / 装饰
        └─ 「光速启动」──第一人称跃迁动画──▶ 飞行模式
                                               │
                          勘测行星 / 击毁敌机 / 完成合约 → CR + 经验
                                               │
                                       右侧「终止航行」
                                               │
                                     返航跃迁 → 船坞对接动画
                                               │
                                     结算维修（消耗 CR）→ 装配台
```

硬约束：

1. 进入站点只会落在装配台，不存在绕过装配直接起飞的入口。
2. 首次进入只有基础装备，全部高级件需要 CR 解锁。
3. 每次巡航结束必须进入维修结算，维修消耗 CR。
4. CR 总量固定在右上角；「终止航行」固定在界面右侧。
5. 飞行模式武器同时包含**激光**与**可追踪导弹**。

## 2. 首次装配流程

1. 加载后先决定落点：无 `profile` → `shipyard/`；有 `?from=shipyard&launch=1` → 飞行；其余直达入口同样回到 `shipyard/`。
2. 装配台展示当前舰与唯一一套基础装备：

| 槽位 | 基础件 | 说明 |
| --- | --- | --- |
| 船体 | 侦察舰体 `hull-scout` | 轻、脆、推进友好 |
| 引擎 | 离子推进器 `engine-ion` | 推力最低，够用 |
| 护盾 | 偏导护盾 `shield-deflector` | 基础防护 |
| 武器 ×2 | 脉冲激光 `weapon-pulse` | 双联激光 |
| 驾驶舱 | 单人座舱 `cockpit-solo` | 无加成 |
| 尾翼 | 矢量尾翼 `tail-vector` | 基础机动 |
| 装饰 | 空 | 可选装配 |

3. 未解锁零件在零件库中以「锁定」态显示：暗化缩略图 + 价格标签 + 锁形图标；点击弹出解锁确认，CR 不足时给出差额提示。
4. 首次进入不预置任何高级蓝图到当前舰；机库示例方案只作展示，载入时自动跳过未解锁零件。

## 3. 积分经济

### 3.1 获取

| 来源 | CR | 经验 |
| --- | --- | --- |
| 击毁敌对拦截机 | +45 | +8 |
| 勘测一颗行星 | +120 | +20 |
| 合约 · 勘测 | +180 | +60 |
| 合约 · 清剿 | +220 | +80 |
| 合约 · 回收 | +260 | +90 |

军衔：见习舰长（0）→ 上尉（120）→ 少校（320）→ 星区指挥官（640）。军衔只影响展示与解锁折扣，不直接给数值碾压。

### 3.2 解锁价格

| 档位 | 代表件 | 价格 |
| --- | --- | --- |
| 基础 | 初始套装 | 0（默认拥有） |
| 一期 | `engine-pulse`、`weapon-beam`、`shield-phase`、`hull-line` | 600 |
| 二期 | `engine-fusion`、`weapon-rail`、`shield-aegis`、`cockpit-command` | 1 200 |
| 三期 | `engine-singularity`、`weapon-torpedo`、`hull-bastion`、`cockpit-neural` | 2 400 |
| 装饰 | 8 种外观件 | 180 – 420 |

新档案初始 CR：**300**（足够解锁一件一期件，形成第一次明确选择）。

### 3.3 消耗：维修

- 每次巡航结束（终止航行 / 被击毁 / 任务完成返航）都记录舰体完整度 `hull`。
- 维修费用：`ceil((100 - hull) / 100 × 240) + 40`，即最低 40 CR 的基础检修费，全损约 280 CR。
- 结算界面给出「支付并维修」「仅支付可负担部分」「暂不维修」三种选择：不维修则下次出航带着残损舰体起飞。
- 破产保护：CR < 40 时允许欠费一次，维修后 CR 归零，并在下一次结算提示。

### 3.4 闭环节奏

一次中等巡航（2 次击杀 + 1 颗行星 + 1 份合约）≈ 510 CR；一次中度受损维修 ≈ 90 CR。约 5–7 次巡航可解锁一件三期件，避免「一把毕业」。

## 4. 界面布局

### 4.1 飞行 HUD

- **右上角固定 CR 总量**：`◈ 1 240 CR`，等宽数字，变化时数字滚动 + 绿色增量浮标。
- **右侧「终止航行」**：竖向贴在右边缘中部，琥珀色描边；点击进入确认态（「确认返航 · 结算维修」/「继续航行」）。
- 击毁敌机：右上角 CR 旁弹出 `+45 CR` 浮标（上浮 24px、320ms 淡出），同时屏幕中心击杀标记 + 冲击闪光。
- 武器区：激光热量条 + 导弹弹药点（4 发），过热/装填状态文案。
- 积分变化与战斗结果都走同一套「右上角浮标」语言，避免玩家在两个角落找信息。

### 4.2 装配台

- 左：零件库（含锁定态与价格）。
- 中：3D 船坞，零件替换播放拆下 / 飞入 / 吸附动画。
- 右：性能与 CR；底部「光速启动」。
- 返航后：右栏顶部出现维修结算卡（费用、舰体条、按钮），处理完才恢复常规面板。

## 5. 武器与战斗手感

### 5.1 激光（主武器）

- 双联脉冲，0.18s 冷却，热量 +5.2/发，100 过热；自动锁定 17° / 780 单位内最近目标。
- 命中：白闪 + 火星 + 短促金属音；击毁：橙红爆闪、冲击波环、0.12s 命中停顿、镜头抖动。

### 5.2 可追踪导弹（副武器）

- 4 发/架次，单发冷却 3.2s，锁定后发射，2.2 秒内以 2.6 倍弹速追踪，命中造成 38 点伤害并产生二次爆炸。
- 无锁定也可发射（直飞），命中率低；锁定目标后导弹拖尾更亮，HUD 提示「LOCK」。
- 导弹与激光共用目标系统，避免玩家管理两套锁定。

### 5.3 击毁反馈分层

1. 瞬时：命中停顿 + 镜头抖动 + 敌方护盾/舰体条清空。
2. 空间：爆炸球 + 环状冲击波 + 碎片。
3. 信息：屏幕击杀标记、右上角 `+45 CR`、CR 数字滚动。
4. 声音：低频冲击 + 高频碎裂 + 延迟的回响。

## 6. 返航与船坞

1. 右侧「终止航行」→ 确认。
2. 飞行侧：跃迁充能 → 白光过曝 → 舰体拉出星轨（约 1.1s）。
3. 进入 `shipyard/?return=1`：船坞对接动画（舰体从深空滑入、夹具合拢、灯光扫过）。
4. 对接完成弹出维修结算卡：舰体完整度、费用、支付按钮。
5. 结算后回到装配台，可继续改装配件或再次出航。

## 7. 数据与持久化

| Key | 内容 |
| --- | --- |
| `stellar_odyssey:profile:v1:<accountId>` | credits、xp、rank、unlocked[]、hull、runs、kills、surveys、firstRunDone |
| `stellar_odyssey:contracts:v1:<accountId>` | active / completed / issued（合约进度） |
| `stellar_odyssey:builds:v1` | 机库方案 |

迁移：若存在旧版 `contracts` 中的 credits，首次读取时并入 `profile.credits`，避免玩家资产丢失。
